# TableHub Backend Services
# Architecture: Microservices with Spring Boot 3.2.5 + Java 21
# Services: auth, user, restaurant, table, slot, reservation, payment, notification
# Shared: common library (DTOs, exceptions, enums, constants)
# Infrastructure: API Gateway, Service Registry (Eureka), Config Server
# Database: PostgreSQL 16 (shared schema, JPA/Hibernate)
